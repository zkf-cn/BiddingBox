# 招标百宝箱 · 招投标咨询在线计算与查询

面向工程招标代理、造价咨询从业人员的**纯前端 SPA 工具集**：9 套工程计费计算器 + 工期定额查询 + 评标专家专业分类查询。
全部计算在浏览器本地完成，**用户数据不上传服务器**。

## 功能

### 9 套计费计算器

| 计算器 | 依据文号 |
| --- | --- |
| 招标代理服务费 | 计价格〔2002〕1980号 / 发改办价格〔2003〕857号 |
| 造价咨询服务费（8 类） | 中价协〔2013〕35号 |
| 工程设计费 | 计价格〔2002〕10号 |
| 施工监理费 | 发改价格〔2007〕670号 |
| 前期工作咨询费 | 计价格〔1999〕1283号 |
| 环境影响咨询费 | 计价格〔2002〕125号 |
| 建设单位管理费 | 财建〔2016〕504号 |
| 代建管理费 | 闽发改法规〔2016〕613号 |
| 工程交易服务费 | 闽发改服价〔2024〕150号 |

统一交互：输入即算、未打折/调整系数两套结果对比、导出 xlsx（含输入参数、两套结果、政策文号、标准全称）、可手动加入统计列表、校验失败清空结果区并给中文提示。

### 2 个查询模块

- **工期定额查询**：TY01-89-2016 建筑安装工程工期定额，2645 条，支持筛选检索、多选、批量导出、收藏
- **评标专家分类查询**：发改法规〔2018〕316号，1793 项，四级分类，同上能力

### 全局能力

浅色/深色主题切换（持久化）、一键清空本地缓存、响应式布局（移动端侧边栏自动收起）、浏览器打印兼容。

## 快速开始

```bash
npm install
npm run dev       # 开发调试 http://localhost:5173
npm run build     # 生产构建，产物在 dist/
npm run preview   # 预览构建产物
```

## 项目结构

```
src/
├── config.js           # 站点配置：数据版本声明、导出上限、统计 ID、存储键
├── data/               # 原始数据（JSON，政策更新只改这里）
│   ├── standards.json  # 9 套计费标准费率表 + 文号
│   ├── quota.json      # 工期定额 2645 条
│   └── expert.json     # 评标专家分类 1793 项
├── utils/              # 计算引擎、校验、存储、格式化、xlsx 导出
├── composables/        # 主题、Toast
├── components/         # 侧边栏、顶部导航、图标、提示、确认框
├── views/
│   ├── calc/defs.js    # 9 套计算器的配置定义（配置驱动核心）
│   ├── calc/CalcView.vue
│   ├── HomeView.vue / QuotaView.vue / ExpertView.vue / AboutView.vue
├── styles/             # 主题变量 CSS + 基础样式
└── router/             # 路由
scripts/
├── extract-data.mjs    # 从旧版项目抽取数据为 JSON
├── gen-404.mjs         # 构建后生成 404.html + .nojekyll
└── verify-calc.mjs     # 计算引擎回归验证（14 条政策算例）
```

## 验证

```bash
node scripts/verify-calc.mjs
```

覆盖 9 套计算器的 14 条回归用例（含节点值命中、档位下边界、内插计算），全部通过方可发版。

Vue 3.5 + Vue Router 4 + Vite 5 + SheetJS(xlsx) 0.18，无后端、无 UI 框架依赖。
